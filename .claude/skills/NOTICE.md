# Third-party skills used in this project

The skills in this directory are copied from public repositories, not written for this
project. They were used to structure the deliverables in `docs/`, `slides/`, and
`mockups/`. Credit and license terms below.

## Product Manager Skills
`prd-development/`, `opportunity-solution-tree/`, `problem-framing-canvas/`,
`jobs-to-be-done/`, `proto-persona/`

Source: https://github.com/deanpeters/Product-Manager-Skills (Dean Peters)
License: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International.
These five folders remain under that license. See each folder's own SKILL.md for
the full framework description.

## Wireframe
`wireframe/`

Source: https://github.com/Magdoub/claude-wireframe-skill
License: MIT. Its default workflow assumes an existing codebase to scan for design
context; this project has none (it's a net-new concept), so the mockups in
`mockups/` were hand-built by hand following the same B&W wireframe visual language
rather than by running the skill's automated pipeline.
